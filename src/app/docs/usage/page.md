### Adding a screenshot

The `figure` Markdoc tag renders an image with a caption. Add your image to
`public/images/`, then add a self-closing `figure` tag with `src`, `alt`, and
`caption` attributes to any doc page (see `src/markdoc/tags.js` for the tag
definition).
